# Журнал решений

`Время (UTC) — Решение — Почему`. Полный контекст — в коммитах.

- **22:32 — Стек.** FastAPI + SQLAlchemy 2 async + Alembic + PostgreSQL 16 +
  Redis (pub/sub + lock) + httpx; frontend React 18/TS/Vite + TanStack Query
  + Tailwind + Recharts; Docker Compose; почта — эмуляция (outbox в БД,
  реальный SMTP опционально через env). *Почему не Django+Celery: нагрузка —
  тысячи лёгких I/O-задач с суб-минутными per-check интервалами; один
  asyncio-шедулер закрывает это без брокера. Celery beat — под статическими
  расписаниями, Django admin не нужен (свой UI). SSE вместо WebSocket:
  поток однонаправленный, у EventSource бесплатный reconnect. Redis — только
  фан-аут и leader-lock; состояние домена в PG, деградация Redis не рушит
  проверки. Outbox делает письма доказуемыми в UI.* Отвергли: Go (стек
  заказчика — Python), TimescaleDB (date_bin по индексу на ~90K строк/мес —
  единицы мс).
- **22:35 — Домен.** Порог падения = N последовательных неудач (per-check
  1–10, дефолт 3), до порога статус остаётся `up`. Инцидент: открывается на
  пороге, `started_at` = первая неудача серии, закрывается первым успехом.
  Письма: ровно одно DOWN и одно UP на инцидент. Окно обслуживания (на
  проверку или группу): проверки идут, инциденты пишутся, письма
  suppressed; после конца окна при живом падении DOWN отправляет проход
  шедулера (≤тик). UP внутри окна задним числом не отправляется
  (компромисс, см. STATE). Самопараллельность исключена атомарным claim
  `in_flight_until` (между процессами, самолечётся по TTL). Расписание:
  `next_run_at = диспетчеризация + интервал`, слоты не навёрстываются;
  рестарт → продолжение с прежними настройками, простой = дыра в истории,
  не падение. Последний результат денормализован на строке проверки.
  История: date_bin на лету (сутки/5м, неделя/1ч, месяц/6ч). Статус группы
  вычисляемый. Публичная страница: `public_slug` группы + флаг проверки.
  Auth: email+пароль (argon2) + JWT; SSE-токен в query (EventSource не
  умеет заголовки). Всё в UTC, фронтенд конвертирует.
- **22:40 — Эмулятор.** `demo-sites` (мелкий FastAPI): режимы
  ok/error/dead/slow/flaky, переключаются `POST /mode/{name}`; страница
  «Demo» в UI позволяет уронить сайт без curl.
- **22:50 — Дизайн и инструменты.** Токены прогнаны валидатором
  dataviz-скилла (dark, surface #0f172a): контраст всех цветов ≥3:1 — PASS;
  категориальные фейлы не применимы — статусные цвета по одному и всегда с
  подписью, серия одна. Пакеты — uv (loc коммитится), тесты — pytest
  (указание заказчика).
- **23:59 — Баги e2e (закрыты коммитами).** (1) merge ORM-инстанса из claim
