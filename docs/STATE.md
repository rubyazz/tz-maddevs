# Состояние проекта (честно)

Проверено на живом стенде `docker compose up`; сценарии и выводы — в
[PROOF.md](PROOF.md).

## Работает полностью

- CRUD проверок/групп: добавить, редактировать, пауза/резюм, удалить,
  «запустить сейчас»; интервалы 30–3600с и таймауты 1–30с валидируются
  схемой и CHECK-констрейнтами БД.
- Шедулер: claim исключает самопараллельность (доказано 409 и нагрузкой),
  расписание в БД, переживает рестарт, простой не создаёт инцидентов.
- Инциденты: порог N неудач (per-check), `started_at` = первая неудача,
  закрытие первым успехом, длительность в журнале.
- Письма: ровно одно DOWN/UP на инцидент, тишина между; эмуляция outbox +
  Mailbox (sent/suppressed с причиной); реальный SMTP опционален env'ом
  (на живом SMTP-сервере не проверялся — не было SMTP).
- Окна обслуживания: подавление писем с доказуемой записью; отложенное
  DOWN-письмо после конца окна уходит ≤5с.
- Realtime: SSE, две вкладки получают одинаковые события, публичный поток
  фильтруется по slug и флагу проверки.
- История: date_bin-агрегации, график ответа + полоса доступности +
  инциденты; месяц на ~85K строк — 0.17с.
- Нагрузка: 50×30с — ровно по 2 результата на проверку за 75с, висящий
  сайт никого не задерживает, overview 0.28с.
- Публичная страница без входа, только разрешённое.
- Тесты 41 (юнит + DB + API), `make test`; ruff; GitHub Actions
  (lint/test/build ×2).

## Осознанные компромиссы

1. UP-письмо внутри окна обслуживания не отправляется задним числом
   (шум); DOWN после конца окна — уходит, как требует ТЗ.
2. SSE-токен в query — EventSource не умеет заголовки; публичный поток
   токена не содержит.
3. Ретеншн сырых результатов 90 дней, rollup-таблиц нет (месяц и так
   0.17с).
4. Шедулер один (Redis leader-lock); шардирование не делали.
5. Один uvicorn-воркер в демо; фан-аут через Redis к масштабированию готов,
  но конфиг не проверяли.

## Не делали

- E2E-тесты Playwright (вместо них — живой браузерный прогон, PROOF.md).
- Реальная отправка почты (нет SMTP в окружении; транспорт реализован).
- i18n UI (английский), метрики/трейсинг — вне объёма задания.
